# Continuity Agent 2분 데모 영상 대본·스토리보드

## 영상 콘셉트

- **한 줄 메시지:** 끊긴 순간에도, 목표는 이어집니다.
- **러닝타임:** 1분 57초 내외 + 엔드카드 3초
- **형식:** 실제 데스크톱 화면 녹화 중심, 도입과 복귀 순간에만 짧은 상황 연출
- **핵심 서사:** 작업 중단의 문제 → 목표 추론 → 사용자 확인 → 안전한 대행 → 투명한 복구
- **톤:** 차분하고 신뢰감 있게. 질환을 자극적으로 묘사하지 않고 사용자의 주도권과 독립성에 초점을 둔다.

## 내레이션 통합본

갑작스러운 졸림이나 건강상의 이유로 작업이 멈추는 순간, 사라지는 건 몇 분의 시간만이 아닙니다. 하던 일의 목적과 생각의 흐름, 그리고 동료와의 연결까지 끊길 수 있습니다. Continuity Agent는 바로 그 공백을 지킵니다.

사용자가 Gap Mode를 시작하면, 에이전트는 평소처럼 이어지는 작업 흐름에서 현재 목표를 찾습니다. 원문이나 전체 화면을 그대로 보내지 않고, 개인정보를 제거한 활동 정보만 사용합니다.

AI는 명령을 기다리지 않고 목표 후보와 근거, 신뢰도를 제안합니다. 하지만 추론을 사실처럼 단정하지는 않습니다. 최종 목표는 언제나 사용자가 선택합니다.

확인된 목표와 현재 단계, 열린 질문, 다음 행동은 체크포인트로 저장됩니다. 이제 에이전트의 임무는 단 하나, 보고서 작성 흐름을 보존하고 복귀 비용을 줄이는 것입니다.

공백 동안 에이전트는 다음 문단의 개요를 만들고, 관련 자료와 할 일을 정리합니다. 팀 업데이트 전송처럼 외부에 영향을 주는 행동은 정책 엔진을 통과해야 합니다. 이 요청은 실제 전송 대신, 검토 가능한 메시지 초안으로 안전하게 바뀝니다.

사용자가 돌아오면 “Welcome back.” 에이전트는 무엇을 했는지 감추지 않고, 완료된 작업과 보류된 작업, 외부 영향을 먼저 알려 줍니다.

복구 브리프에는 중단 전 목표, 에이전트가 만든 결과물, 대기 중인 결정, 그리고 가장 먼저 이어갈 한 가지 행동이 정리됩니다. 사용자는 개요를 검토하고 수정하거나 내보낸 뒤, 생각을 다시 복원하는 대신 곧바로 다음 문장을 시작합니다.

민감한 앱은 관찰에서 제외되고, 스크린샷은 로컬에만 남으며, 중요한 행동에는 승인이 필요합니다. 더 많은 사람이 예기치 않은 공백 뒤에도 자신의 일상을 스스로 이어가도록.

Continuity Agent. 끊긴 순간에도, 목표는 이어집니다.

## 촬영·편집 체크리스트

### 데모 전 준비

- API는 검증된 fixture provider로 실행하고, 목표 후보와 결과 데이터가 확정적으로 재현되게 한다.
- Word에 `Final Project Report.docx`를 열고 QR factorization 안정성 문단을 반쯤 작성해 둔다.
- Chrome에는 QR factorization 안정성 관련 검색 결과 또는 논문 페이지를 열어 둔다.
- 대시보드는 `Ready when you are` 상태에서 시작하고 이전 Gap 기록은 화면에 보이지 않게 정리한다.
- 전체 흐름을 한 번에 찍기보다 `도입 작업 화면 / 목표 확인 / Gap 실행 / 복구 / 권한` 다섯 구간으로 나누어 녹화한다.
- 목표 추론의 실제 20초 대기 구간은 후반 작업에서 3배속 처리한다. 클릭 직후 결과가 뜨는 것처럼 잘라 과장하지 않는다.

### 화면에서 반드시 잡을 증거

1. 목표 후보의 **84% 신뢰도와 근거 파일명**
2. 사용자가 직접 목표를 선택하는 클릭
3. 확정된 목표 경로와 checkpoint
4. `Agent proposal → Policy check → Safe tool`의 안전 경계
5. 이메일이 전송되지 않고 **메시지 초안으로 전환**되는 결과
6. Recovery의 **Completed / Pending / External effects: None**
7. 추천 다음 행동과 artifact의 **Edit / Export** 기능
8. 민감 앱 제외, 로컬 스크린샷, 승인 중심의 개인정보 보호

### 편집 원칙

- UI 확대는 110~125% 이내로 유지하고 클릭 지점에는 0.3초짜리 원형 하이라이트를 넣는다.
- 기술 아키텍처는 1:03 부근의 3단계 모션 그래픽 하나로만 설명한다.
- 배경 음악은 80~90 BPM의 잔잔한 전자음 계열로, 내레이션보다 최소 15 dB 낮게 둔다.
- 도입부는 저채도, Goal 확정부터 브랜드 블루, Recovery에서는 밝은 톤으로 색감이 회복되게 한다.
- 최종본은 1분 57초를 목표로 편집해 발표 환경의 재생 지연을 포함해도 2분을 넘지 않게 한다.
